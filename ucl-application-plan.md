# UCL MSc application plan

## Decision

UCL is the preferred external route. The department has confirmed that it cannot pre-assess the qualification and that the taught MSc would normally be a complete one-year programme. RPL/APL is not generally considered for the programme and, where an application is made, any recognition is discretionary and must be assessed formally.

## What to prepare before applying

- Current CV with the PGDip result stated as **Postgraduate Diploma in Network & Information Security — Distinction**.
- Official Kingston transcript and award letter.
- Module descriptors for the completed Level 7 modules.
- MyMark dissertation and a concise one-page project summary.
- Undergraduate dissertation, “How do we decide what we provide?”, plus the supporting presentation if requested.
- Two independent academic/professional references.
- A personal statement explaining the move from security research to information-security study, with concrete evidence from GMT Electrical Services and BstudioB.
- Proof of English-language eligibility if UCL requests it.

## Personal-statement spine

1. The problem: safer technology decisions often fail at the point where evidence must become action.
2. Preparation: Network & Information Security study with Distinction, plus practical systems work.
3. Evidence: Device Provisioning Toolkit, the undergraduate research question and MyMark’s focus on provenance, abuse and sextortion.
4. Fit: UCL’s Information Security MSc provides the deeper technical and research environment needed to test these ideas rigorously.
5. Outcome: build security work that people can understand, adopt and trust.

## Important constraint

Do not describe the route as a confirmed top-up. The current UCL position is a fresh full-MSc application, with any RPL decision made only through the formal process.

## Immediate next actions

1. Request the official Kingston transcript and module descriptors.
2. Finalise the CV and personal statement using the evidence above.
3. Confirm the current UCL deadline, fee and funding position in the application portal before paying.
4. Submit only after reviewing the completed application and attachments together.
