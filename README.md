# Nathan Brown-Bennett Portfolio

Source for Nathan Brown-Bennett's GitHub Pages portfolio: cybersecurity research, practical software delivery, professional experience and creative practice. Company products now live at [BstudioB.co.uk](https://bstudiob.co.uk/).

Nathan is a cybersecurity researcher and software builder who turns difficult safety problems into useful systems, evidence and public conversations. His public work is organised across the [portfolio](https://nathanbrownbennett.github.io/NathanBrown-Bennett/), [GitHub](https://github.com/NathanBrownBennett), [technical Instagram](https://www.instagram.com/nxth.b/) and [creative Instagram](https://www.instagram.com/n.brown02/).

## Structure

- `index.html` — personal landing page, profile, contact form, social proof and routes into the portfolio.
- `research.html` — public dissertation, presentation and research artefact library.
- `professional-work.html` — recruiter-facing experience and capabilities.
- `creative-practice.html` — music, spoken word, performances and media.
- `script.js` — shared navigation, reveal animations and contact interactions.
- `styles.css` — responsive presentation and accessibility states.
- `assets/projects/recent/` — real screenshots used by the featured case studies.
- `assets/documents/` — public dissertations and presentations linked from the relevant work.
- `output/pdf/` — recruiter-facing portfolio and ATS CVs.

Only repositories explicitly listed in `CURATED_ARCHIVE` are loaded into the public archive. Experimental, cancelled and private-in-development products are not added automatically.

The site is deployed from `main` through GitHub Pages.
